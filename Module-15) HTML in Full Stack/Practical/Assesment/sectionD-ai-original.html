💬 Exact Prompt Given to ChatGPT
Write a JavaScript program in a single HTML file that: 1. Fetches a list of food items from https://jsonplaceholder.typicode.com/posts (treat each post title as a dish name) using fetch() and async/await. 2. Renders the items in an HTML ul, with an 'Add to Favourites' button next to each item. 3. Saves the user's favourite items to localStorage and re-loads and highlights them correctly when the page is refreshed. 4. Shows a loading indicator while the fetch is in progress. 5. Displays a visible error message in the DOM if the request fails.
🐛 Known Bugs Found During Manual Testing
1
No res.ok check
The AI calls res.json() immediately after fetch() without checking if the response was successful. A 404 or 500 HTTP status would still attempt to parse, and the DOM error element would never appear.
2
Duplicate favourites in localStorage
Every click on "Add to Favourites" pushes the same title into the array again — no duplicate check. The array grows unboundedly (e.g. ["Paneer","Paneer","Paneer"]).
3
Unreliable highlight restore on reload
Restore logic uses li.textContent which includes the button text, so the saved title never matches and highlights are never restored after reload.
