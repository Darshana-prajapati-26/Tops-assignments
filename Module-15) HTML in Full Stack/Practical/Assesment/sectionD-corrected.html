✅ Bugs Fixed (Found Without AI)
Fix 1
Added res.ok check before res.json()
The original called res.json() even for error HTTP responses (404, 500). Added if (!res.ok) throw new Error(...) so all non-2xx responses fall into the catch block and show a visible DOM error message.
Fix 2
Duplicate guard for localStorage favourites
Every click was pushing the same title again. Fixed with if (!favs.includes(title)) before pushing. Also converted the button to a toggle (add/remove) so users can unfavourite items.
Fix 3
Reliable title matching on page reload
The original matched li.textContent which included button text, so saved highlights were never restored. Fixed by storing the title in data-title on each li and comparing against that attribute instead.
