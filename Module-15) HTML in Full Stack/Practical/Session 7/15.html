Q15: Event Flow in the DOM

What is Event Flow?

Event flow describes the order in which events are received by elements in the DOM when an event occurs. There are two phases: event capturing (the event travels from the root down to the target element) and event bubbling (the event travels back up from the target to the root). By default, most event listeners use the bubbling phase.

🛒 Flipkart Example (Event Bubbling):

Suppose you have a product card <div class="product-card"> with a listener for click that opens the product detail page. Inside it there's an <button>Add to Cart</button>. When the user clicks "Add to Cart", the click event first fires on the button, then bubbles up to the parent div — accidentally triggering the "open product detail" handler too. The fix is to call event.stopPropagation() inside the button's handler to prevent the event from bubbling further.
