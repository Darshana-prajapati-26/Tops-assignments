Q12: Refactor Callback → Promise

Q12

Refactor the following callback-based code to use Promises instead: setTimeout(function() { console.log('Payment successful!'); }, 1000); Ensure the new function returns a Promise and logs the message after 1 second.
Hint: Use new Promise((resolve, reject) => { ... }) and resolve inside setTimeout.

❌ Original Callback-based Code

setTimeout(function() {
  console.log('Payment successful!');
}, 1000);

Problem: Can't chain, can't handle errors, no return value.

✅ Refactored Promise Version

function processPayment() {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve('Payment successful!');
    }, 1000);
  });
}

processPayment()
  .then(message => console.log(message));
