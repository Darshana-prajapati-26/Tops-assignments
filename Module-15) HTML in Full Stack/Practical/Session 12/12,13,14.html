📝 Request–Response Cycle Explanation

Request: The browser sends an HTTP GET request to https://jsonplaceholder.typicode.com/users. The request includes headers such as Accept: */* and the HTTP method. No request body is sent because GET requests only ask for data.

Response: The server replies with a 200 OK status code and a JSON array of 10 user objects in the response body. The Content-Type: application/json header tells the browser how to interpret the data. The browser then makes it available to our JavaScript via .json().
