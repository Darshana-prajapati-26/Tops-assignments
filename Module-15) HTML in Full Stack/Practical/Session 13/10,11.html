Q10 & Q11: Debug – Accessing Property of Undefined

Q10 & Q11

Debug this code so that it properly handles errors when trying to access a property of an undefined object:

let user;
try {
  console.log(user.name);
} catch (e) {
  // handle error
}

Hint: Make sure the error message is user-friendly, like 'User data not found'.

❌ Buggy Code

let user;
try {
  console.log(user.name);  // TypeError: Cannot read properties of undefined
} catch (e) {
  // handle error  ← empty catch, no user-friendly message
}

Problem: The catch block is empty — the error is silently swallowed and the user sees nothing.

✅ Fixed Code

let user;  // undefined
try {
  console.log(user.name);
} catch (e) {
  console.error("User data not found");   // user-friendly message
}
