Q12: Fix formatFollowers() – Throw Error Objects, not Strings

Q12

You are given this buggy code: function formatFollowers(count) { try { if(count < 0) throw 'Negative count'; return count + ' followers'; } catch(e) { return e.message; } }. It should return the error message if count is negative, but it returns undefined. Fix the code so it properly throws and catches an Error object.
Hint: Use Error objects instead of strings for throwing and catching errors.

❌ Buggy Code

function formatFollowers(count) {
  try {
    if (count < 0) throw 'Negative count';  // throws a STRING, not an Error
    return count + ' followers';
  } catch (e) {
    return e.message;  // strings don't have .message — returns undefined!
  }
}

Bug: throw 'Negative count' throws a plain string. Strings don't have a .message property, so e.message is undefined.

✅ Fixed Code – Use new Error()

function formatFollowers(count) {
  try {
    if (count < 0) throw new Error('Negative count');  // ✅ Error object
    return count + ' followers';
  } catch (e) {
    return e.message;  // ✅ 'Negative count'
  }
}
