Q13 & Q14: Debug – localStorage Array Not Displaying Correctly

Q13 & Q14

Debug this code: It tries to save an array of movie names to localStorage, but after reloading, the list doesn't display correctly.

let movies = ['Jawan', 'Pathaan', 'Dunki'];
localStorage.setItem('movies', movies);
let saved = localStorage.getItem('movies');
let arr = JSON.parse(saved);
console.log(arr);

Hint: Check how movies is being stored and what type localStorage expects.

❌ Buggy Code

let movies = ['Jawan', 'Pathaan', 'Dunki'];
localStorage.setItem('movies', movies);   // BUG: stores as comma-separated string, not JSON
let saved = localStorage.getItem('movies');
let arr = JSON.parse(saved);              // ERROR: "Jawan,Pathaan,Dunki" is not valid JSON
console.log(arr);

Bug: localStorage.setItem() calls .toString() on the array, storing it as "Jawan,Pathaan,Dunki" (a plain string). JSON.parse() then throws a SyntaxError because that is not valid JSON. The fix is to use JSON.stringify() before storing.

✅ Fixed Code

let movies = ['Jawan', 'Pathaan', 'Dunki'];
localStorage.setItem('movies', JSON.stringify(movies));  // ✅ store as JSON string
let saved = localStorage.getItem('movies');
let arr = JSON.parse(saved);                             // ✅ parse back to array
console.log(arr);
