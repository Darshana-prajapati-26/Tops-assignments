Q10 & Q11: Movie Class – Refactor from Function Constructor

Q10 & Q11

Refactor the following code to use a class instead of a function constructor:

function Movie(title, genre) { this.title = title; this.genre = genre; }
Movie.prototype.display = function() { console.log(this.title + ' - ' + this.genre); }

Make sure your new class works the same way.

❌ Old — Function Constructor (original code)

function Movie(title, genre) {
  this.title = title;
  this.genre = genre;
}
Movie.prototype.display = function() {
  console.log(this.title + ' - ' + this.genre);
};

✅ New — Class Syntax (refactored)

class Movie {
  constructor(title, genre) {
    this.title = title;
    this.genre = genre;
  }
  display() {
    console.log(this.title + ' - ' + this.genre);
  }
}
