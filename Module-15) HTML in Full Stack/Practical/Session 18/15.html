💬 My Explanation in Own Words

Error triggered:
TypeError: Cannot read properties of undefined (reading 'name')

What ChatGPT explained:
This error means JavaScript tried to access the .name property on something that is undefined. It is like trying to open a drawer in a cabinet that does not exist — the cabinet (user) was never created, so there is no drawer (name) to open.

How to fix it:
Always check that the variable is not undefined before accessing its properties. Use optional chaining: user?.name, or a guard: if (user) console.log(user.name);

In my own words:
The error happened because I tried to use user.name when user was never assigned a value. JavaScript cannot look inside something that does not exist. The simple fix is to check if the variable exists first before using it.
