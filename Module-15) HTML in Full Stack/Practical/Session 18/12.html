Q12: Stack Trace – getUser / fetchUser Bug

Q12

Run the buggy code and use the stack trace to identify which function and line caused the error. Write down the function name and line number.
Hint: Expand the error in DevTools Console to view the call stack.

❌ Buggy Code

function getUser()   { return fetchUser(); }
function fetchUser() { return JSON.parse(undefined); }  // 💥 BUG HERE
getUser();

Bug: JSON.parse(undefined) throws SyntaxError — fetchUser() is the culprit.

✅ Fixed Code

function getUser()   { return fetchUser(); }
function fetchUser() {
  const raw = undefined;
  if (raw === undefined || raw === null) return null; // ✅ guard
  return JSON.parse(raw);
}
getUser();
