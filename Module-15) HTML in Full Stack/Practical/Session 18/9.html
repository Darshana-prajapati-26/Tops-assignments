Q9: Breakpoint in a Loop – Friends Array

Q9

Open DevTools Sources tab, set a breakpoint inside the loop, and step through to inspect the loop variable (friend) at each iteration.
Hint: F8 = continue to next breakpoint, F10 = step over one line.

🔴 How to Set the Breakpoint

  1. Open DevTools → Sources tab (F12)
  2. Locate this HTML file in the file tree
  3. Click the line number next to console.log(friend) — a red dot appears
  4. Click "Run Loop" below
  5. Execution pauses on each iteration — hover over friend and i
  6. Press F10 to step to the next line, F8 to continue to the next iteration
// Code to step through:
const friends = ["Rahul", "Priya", "Amit", "Sneha", "Rohan"];
for (let i = 0; i < friends.length; i++) {
  const friend = friends[i];   // 👈 Set breakpoint here
  console.log(friend);
}
