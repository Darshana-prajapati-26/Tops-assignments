Q7 & Q8: Refactor – Event Delegation for Instagram Story Cards

Q7 & Q8

Given code where individual event listeners are added to each Instagram story card for removal, refactor it to use a single event listener on the parent container (event delegation).
Constraint: Do not use more than one event listener for all cards.

❌ Before – Individual listeners on each card (inefficient)

// BAD: a new listener is created for every card
document.querySelectorAll(".dismiss-btn").forEach(btn => {
  btn.addEventListener("click", function () {
    this.closest(".story-card").remove();
  });
});

✅ After – Single delegated listener on parent (efficient)

// GOOD: one listener handles ALL cards, including dynamically added ones
document.getElementById("stories-container").addEventListener("click", function (e) {
  if (e.target.classList.contains("dismiss-btn")) {
    e.target.closest(".story-card").remove();
  }
});
