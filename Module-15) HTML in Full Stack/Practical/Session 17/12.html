Q12: Bug Fix – Use Event Delegation Instead of Loop

Q12

Fix the bug so that clicking the 'X' icon on any card removes only that card, even if cards are added dynamically.

document.querySelectorAll('.remove-btn').forEach(btn => { btn.addEventListener('click', function() { this.parentElement.remove(); }); });

Hint: Use event delegation by adding a single event listener to the parent container instead of looping through all buttons.

❌ Buggy Code – forEach loop doesn't cover dynamically added cards

// BUG: querySelectorAll only finds existing elements at this point in time.
// Cards added later won't have the listener!
document.querySelectorAll('.remove-btn').forEach(btn => {
  btn.addEventListener('click', function() {
    this.parentElement.remove();
  });
});

Problem: If a new card is added dynamically after this code runs, its button won't have a listener — so clicking 'X' on it does nothing.

✅ Fixed Code – Single delegated listener on parent container

// FIX: One listener on the parent catches clicks from ALL buttons,
// including those added dynamically later.
document.getElementById('card-container').addEventListener('click', function(e) {
  if (e.target.classList.contains('remove-btn')) {
    e.target.closest('.item-card').remove();
  }
});
