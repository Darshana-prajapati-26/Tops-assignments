Q3

Sketch the architecture for a Flipkart-style Wishlist Manager: show how data flows from the Add Item form → storage (array/localStorage) → display list, and how edit/delete actions update both data and UI.

📐 Data Flow Diagram

Add Flow:
📝 Add Item Form
(name, price)
→
💾 wishlist[] Array
(+ localStorage)
→
🖥️ Display List
(re-render)
Edit Flow:
🖥️ Display List
→
✏️ Edit Button
(pre-fill form)
→
📝 Form
(update values)
→
💾 Update Array
(+ localStorage)
→
🖥️ Re-render
Delete Flow:
🖥️ Display List
→
🗑️ Delete Button
(splice index)
→
💾 Remove from Array
(+ localStorage)
→
🖥️ Re-render
Steps:
1
User fills Add Item form and clicks "Add"
2
JS reads form values, creates an object, pushes to wishlist[]
3
Array is saved to localStorage for persistence
4
renderWishlist() clears the display and re-renders all items
5
Edit: form pre-fills, user updates, array item is replaced at the same index
6
Delete: array.splice(index, 1) removes the item, UI re-renders
