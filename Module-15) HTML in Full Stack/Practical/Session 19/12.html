Q12: Restaurant Delete Feature – splice() + Re-render

Q12

Implement the Delete feature so that when the user clicks Delete for any restaurant, it is removed from both the array and the displayed list instantly.
Hint: Use array.splice() and re-render the list after deletion.

✅ Delete Implementation

function deleteRestaurant(index) {
  restaurants.splice(index, 1);  // remove 1 item at 'index'
  renderList();                  // re-render the list
}
