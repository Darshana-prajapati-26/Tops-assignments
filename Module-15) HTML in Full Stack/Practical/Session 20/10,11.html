Q10 & Q11: Bug Checklist

Open the browser console (F12) and click each test button below to trigger common bugs:

#BugDescriptionFix
1 Double Add Clicking "Add to Cart" multiple times adds the same item more than once. Check if item already exists in the array with find() or some() before pushing.
2 Empty Field Submit Form submits even when input fields are blank. Validate with if (!value.trim()) and show an error message. Return early to prevent submission.
3 Null / Undefined Push null or undefined values get added to an array. Add a guard: if (!name || name.trim() === "") return; before pushing.
4 Cart Count Not Updating The displayed cart count does not change after adding or removing items. Always update the count element after every add/remove: countEl.textContent = cart.length;
5 NaN Rating Parsing an empty rating field returns NaN, which gets stored in the array. Use isNaN(rating) check and validate the range: if (isNaN(rating) || rating < 1 || rating > 5).
