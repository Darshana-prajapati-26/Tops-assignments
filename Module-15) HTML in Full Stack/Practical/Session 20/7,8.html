Q7 & Q8

A Zomato-style Add Review form submits even when the textarea is empty. Fix the bug so it prevents submission and shows a message if the review is blank.

Q7 & Q8: Bug Fix – Empty Review Submission

❌ Buggy Code

function submitReview() {
  const review = document.getElementById("review").value;
  // BUG: no check for empty string — submits even when blank
  console.log("Review submitted:", review);
}

✅ Fixed Code

function submitReview() {
  const review = document.getElementById("review").value.trim();
  if (!review) {
    // Show error — do NOT submit
    document.getElementById("review-err").textContent = "Review cannot be empty.";
    return;
  }
  document.getElementById("review-err").textContent = "";
  console.log("Review submitted:", review);
}
