Q9

The function addFollower(name) sometimes adds null or empty names to the followers array. Fix it so only valid, non-empty names are added.
Hint: Add a check before pushing to the array.

Q9: Bug Fix – addFollower() Validation

❌ Buggy Code

function addFollower(name) {
  // BUG: no check — null and "" get pushed into the array
  followers.push(name);
}

✅ Fixed Code

function addFollower(name) {
  if (!name || name.trim() === "") {
    console.warn("Invalid name — not added.");
    return;
  }
  followers.push(name.trim());
}
