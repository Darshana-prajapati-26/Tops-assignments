Chrome DevTools — console.log('Hello from the console!')
▼
Open Chrome DevTools on any website you visit daily (like Instagram or Zomato), go to the Console tab, and type console.log('Hello from the console!') to see the output.
✅ Answer
  1. Open Chrome → go to instagram.com or zomato.com
  2. Press F12 to open DevTools
  3. Click the Console tab
  4. Type the command below and press Enter
console.log('Hello from the console!');
▶ Console Output: Hello from the console!

Add 'Show Bio' button — Alert with name and favourite app
▼
Add a <button> to your HTML file labeled 'Show Bio', and use JavaScript inside a <script> tag to display an alert with your name and favorite app when the button is clicked.
✅ Answer
<button id="showBioBtn">Show Bio</button> <script> document.getElementById('showBioBtn') .addEventListener('click', function() { alert('My name is Darshana and my favourite app is Instagram!'); }); </script>
▶ Output (Alert on button click): My name is Darshana and my favourite app is Instagram!

9
Add 'Show Greeting' button — Alert 'Hello from JS!'
▼
Modify your insta-bio.html file to add a <button> labeled 'Show Greeting'. When the button is clicked, use JavaScript to show an alert that says 'Hello from JS!'.
💡 Hint: Use document.querySelector and addEventListener to connect the button with your JS code.
✅ Answer
<button id="showGreetingBtn">Show Greeting</button> <script> document.querySelector('#showGreetingBtn') .addEventListener('click', function() { alert('Hello from JS!'); }); </script>
▶ Output (Alert on button click): Hello from JS!
📂 Open insta-bio.html
10
Change <h2> 'Top 3 Food Apps' color to green on page load
▼
Edit your HTML file to include a <h2> tag with the text 'Top 3 Food Apps'. Use JavaScript in a <script> tag to change the color of this heading to green when the page loads.
💡 Hint: Use document.querySelector to select the heading and style.color to change its color.
✅ Answer
<h2 id="foodHeading">Top 3 Food Apps</h2> <script> document.querySelector('#foodHeading').style.color = 'green'; </script>
▶ Live Output (heading turns green automatically):

Top 3 Food Apps


📂 Open insta-bio.html

VS Code Live Server — Update alert with your name
▼
Use VS Code Live Server to open your insta-bio.html file, then change the alert message to include your own name and refresh to see the update.
✅ Answer
  1. Install Live Server extension in VS Code
  2. Right-click insta-bio.html → Open with Live Server
  3. Change the alert text to include your name (see code below)
  4. Save the file — browser auto-refreshes showing updated alert
<script> alert('Welcome to your Insta Bio-Link Page! My name is Darshana.'); </script>
▶ Output (Alert popup): Welcome to your Insta Bio-Link Page! My name is Darshana.
